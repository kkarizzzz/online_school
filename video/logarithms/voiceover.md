**01 · 0:00 — Интро**
Привет! Сегодня разберём свойства логарифмов — всё, что нужно для задания 7 профильного ЕГЭ и для уравнений и неравенств второй части.

**02 · 0:10 — Определение**
Начнём с определения. Логарифм числа b по основанию a — это показатель степени, в которую нужно возвести a, чтобы получить b.
Например, логарифм восьми по основанию два равен трём, потому что два в кубе — восемь.
И важно помнить условия: основание положительно и не равно единице, а число под логарифмом — строго положительно.

**03 · 0:34 — Следствия определения**
Из определения сразу следуют три факта. Логарифм единицы по любому основанию равен нулю, логарифм основания по этому же основанию равен единице.
И основное логарифмическое тождество: a в степени логарифм b по основанию a равно b.
Например, пять в степени логарифм семи по основанию пять — это просто семь.

**04 · 0:56 — Сумма и разность**
Теперь главные свойства. Сумма логарифмов с одинаковым основанием равна логарифму произведения.
Например, логарифм четырёх по основанию шесть плюс логарифм девяти по основанию шесть — это логарифм тридцати шести по основанию шесть, то есть два.
Разность логарифмов — это логарифм частного: логарифм пятидесяти четырёх по основанию три минус логарифм двух — это логарифм двадцати семи, то есть три.

**05 · 1:23 — Степени**
Показатель степени аргумента можно вынести вперёд множителем: логарифм b в степени k равен k, умноженному на логарифм b.
А показатель степени основания выносится как обратное число: делим на k.
Вместе: логарифм b в степени n по основанию a в степени m равен n делить на m, умноженному на логарифм b по основанию a.
Пример: логарифм тридцати двух по основанию восемь. Восемь — это два в кубе, тридцать два — два в пятой. Получаем пять третьих.

**06 · 1:56 — Переход к новому основанию**
Формула перехода к новому основанию: логарифм b по основанию a равен отношению логарифмов b и a по любому новому основанию c.
Отсюда два полезных следствия: логарифм b по основанию a равен единице, делённой на логарифм a по основанию b,
а произведение логарифма b по основанию a на логарифм c по основанию b равно логарифму c по основанию a — основания сокращаются цепочкой.
Пример: логарифм сорока девяти по основанию пять делить на логарифм семи по основанию пять — это логарифм сорока девяти по основанию семь, то есть два.

**07 · 2:34 — Задача ЕГЭ**
Разберём задачу в формате ЕГЭ. Найдите значение выражения: тридцать шесть в степени логарифм пяти по основанию шесть.
Представим тридцать шесть как шесть в квадрате.
Двойку переносим в показатель логарифма: получаем шесть в степени логарифм двадцати пяти по основанию шесть.
По основному тождеству это двадцать пять.

**08 · 2:57 — Ещё одна классика**
Ещё одна классика: логарифм трёх по основанию ноль целых восемь десятых, умноженный на логарифм одной целой двадцати пяти сотых по основанию три.
Это цепочка: тройки сокращаются, остаётся логарифм одной целой двадцати пяти сотых по основанию ноль целых восемь десятых.
Ноль целых восемь десятых — это четыре пятых, а одна целая двадцать пять сотых — пять четвёртых, то есть четыре пятых в минус первой степени.
Ответ: минус один.

**09 · 3:27 — Типичные ошибки**
И частые ошибки. Логарифм суммы не равен сумме логарифмов: такой формулы нет.
При вынесении чётной степени ставим модуль: логарифм b в квадрате равен двум логарифмам модуля b, иначе можно потерять корни уравнения.
И всегда проверяйте ОДЗ: основание больше нуля и не равно единице, аргумент больше нуля.
