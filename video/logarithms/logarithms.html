Шаг 01 · Определение
Что такое логарифм
Логарифм числа b по основанию a
log_{a}b = c ⇔ a^{c} = b
c — показатель степени, в которую возводят a, чтобы получить b
Пример
log_{2}8 = 3
так как 2^{3} = 8
Условия (ОДЗ): a > 0 a ≠ 1 b > 0
Шаг 02 · Следствия определения
Три факта «из коробки»
1Логарифм единицы
log_{a}1 = 0
2Логарифм основания
log_{a}a = 1
3Основное логарифмическое тождество
a^{log_{a}b} = b
Пример
5^{log_{5}7} = 7
Шаг 03 · Сумма и разность
Одинаковые основания — склеиваем
+Логарифм произведения
log_{a}b + log_{a}c = log_{a}(bc)
→log_{6}4 + log_{6}9
=log_{6}(4·9) = log_{6}36
=2
−Логарифм частного
log_{a}b − log_{a}c = log_{a}\frac{b}{c}
→log_{3}54 − log_{3}2
=log_{3}\frac{54}{2} = log_{3}27
=3
Шаг 04 · Степени
Выносим показатели
Степень аргумента
log_{a}b^{k} = k·log_{a}b
Степень основания
log_{a^{k}}b = \frac{1}{k}·log_{a}b
Вместе
log_{a^{m}}b^{n} = \frac{n}{m}·log_{a}b
Пример
log_{8}32
=log_{2^{3}}2^{5}
=\frac{5}{3}·log_{2}2 = \frac{5}{3}
Шаг 05 · Новое основание
Переход к другому основанию
Формула перехода · c > 0, c ≠ 1
log_{a}b = \frac{log_{c}b}{log_{c}a}
Следствие 1
log_{a}b = \frac{1}{log_{b}a}
Следствие 2 · «цепочка»
log_{a}b·log_{b}c = log_{a}c
Пример
\frac{log_{5}49}{log_{5}7}
=log_{7}49
=2

Осторожно · Типичные ошибки
Где теряют баллы
Нет такой формулы
log_{a}(b+c) = log_{a}b + log_{a}c
Логарифм суммы не раскладывается
Чётная степень → модуль
log_{a}b^{2} = 2log_{a}|b|
Без модуля можно потерять корни уравнения
Всегда проверяйте ОДЗ: a > 0 a ≠ 1 b > 0
