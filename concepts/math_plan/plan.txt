│   │   ├── 1.10.1. Понятие логарифма
│   │   │   ├── Определение: log_a(b) = c <=> a^c = b
│   │   │   ├── Ограничения логарифма: основание a > 0, a ≠ 1; подлогарифмическое выражение (аргумент) b > 0
│   │   │   ├── Основное логарифмическое тождество: a^(log_a(b)) = b
│   │   │   ├── Базовые значения: log_a(1) = 0, log_a(a) = 1
│   │   │   └── Специальные обозначения: десятичный логарифм lg(b) = log_10(b), натуральный ln(b) = log_e(b)
│   │   ├── 1.10.2. Свойства суммы и разности логарифмов
│   │   │   ├── Логарифм произведения: log_a(x · y) = log_a(x) + log_a(y) при x > 0, y > 0
│   │   │   ├── Обобщение на неизвестные знаки: log_a(x · y) = log_a|x| + log_a|y| при x·y > 0
│   │   │   ├── Логарифм дроби: log_a(x / y) = log_a(x) - log_a(y) при x > 0, y > 0
│   │   │   └── Обобщение на неизвестные знаки: log_a(x / y) = log_a|x| - log_a|y| при x/y > 0
│   │   ├── 1.10.3. Вынесение показателей степеней
│   │   │   ├── Вынос степени из аргумента: log_a(x^p) = p · log_a(x) при x > 0
│   │   │   ├── Ловушка четного показателя: log_a(x^(2k)) = 2k · log_a|x| при x ≠ 0
│   │   │   ├── Вынос степени из основания: log_(a^q)(b) = (1 / q) · log_a(b)
│   │   │   ├── Вынос четной степени из основания: log_(a^(2k))(b) = (1 / 2k) · log_|a|(b)
│   │   │   └── Комбинированный вынос: log_(a^q)(b^p) = (p / q) · log_a(b)
│   │   ├── 1.10.4. Формулы перехода к новому основанию
│   │   │   ├── Базовая формула перехода: log_a(b) = log_c(b) / log_c(a) при c > 0, c ≠ 1
│   │   │   ├── Переворот основания и аргумента: log_a(b) = 1 / log_b(a)
│   │   │   ├── Произведение взаимных логарифмов: log_a(b) · log_b(c) = log_a(c)
│   │   │   └── Свойство симметричной перестановки оснований: a^(log_c(b)) = b^(log_c(a))
│   │   └── 1.10.5. Сравнение логарифмов
│   │       ├── Монотонность: функция y = log_a(x) возрастает при a > 1, убывает при 0 < a < 1
