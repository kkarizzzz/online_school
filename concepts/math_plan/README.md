# План подготовки к ЕГЭ по математике

Исходный план курса (5 веток × 4 уровня, 72 темы, 315 уроков) и интерактивная карта тем по нему. Отсюда берёт данные вкладка «Теория» (`concepts/theory_page`).

## Файлы

- `plan.txt` — сам план: дерево веток → уровней → тем → уроков. **Правится руками**, это источник правды.
- `template.html` — шаблон карты (вёрстка, стили, скрипты). В нём маркер `/*DATA*/`, куда подставляются данные.
- `parse.py` — разбирает `plan.txt` и собирает из шаблона `ege-map.html`.
- `ege-map.html` — готовая карта: матрица «ветка × уровень», клик по теме открывает подтемы. Генерируется, руками не править.

## Посмотреть карту

Ничего запускать не нужно — откройте `ege-map.html` двойным кликом (или перетащите в браузер). Шрифты грузятся из Google Fonts, без интернета будут системные.

## Пересобрать после правки плана

Из корня репозитория:

```bash
python concepts/math_plan/parse.py
```

Скрипт выведет число веток, уровней в каждой ветке и тем. Затем обновите данные теории:

```bash
python concepts/theory_page/build.py
```

Пути можно переопределить: `python parse.py [plan.txt] [template.html] [ege-map.html]`.

## Формат `plan.txt`

Дерево в стиле `tree`: отступ — 4 символа, ветви `├── ` / `└── `, вертикали `│`. Строка без `├──`/`└──` с отступом считается продолжением предыдущего пункта и приклеивается к нему через « · ».

```
ВЕТКА 1: ЧИСЛА, ВЫЧИСЛЕНИЯ И ТЕОРИЯ ЧИСЕЛ
│
├── УРОВЕНЬ 0: БАЗА 1–6 КЛАСС
│   ├── 1.1. Обыкновенные дроби
│   │   ├── 1.1.1. Понятие дроби (…)
│   │   │   └── пункт урока
```

Номер задания ЕГЭ указывается в скобках у уровня или темы, например `(№7)` или `(ПЕРВАЯ ЧАСТЬ, ЗАДАНИЯ №6, №7)` — `build.py` вытащит его в бейдж «ЕГЭ».
