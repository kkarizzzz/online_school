# Концепт: «Быстрое повторение»

Бесконечная лента коротких вопросов с вариантами ответа: теория (формулы, определения, свойства) и простые вычисления, проще уровня ЕГЭ.

**Стартовый экран** — три большие кнопки режимов: «Теория», «Вычисления», «Микс» (всё вперемешку). На каждой — сколько в режиме вопросов и результат прошлого раза. Ниже мини-статистика прошлых повторений: сколько повторений, ответов, общая точность, лучшая серия и пять последних повторений.

**Лента** — одна карточка с вопросом, фильтров нет:

- Нажали вариант — ответ сразу проверяется, показывается пояснение, кнопка «Дальше».
- «Не знаю» — показывает правильный ответ и засчитывается как ошибка.
- Вопрос с ошибкой возвращается через 3–5 карточек с плашкой «Повтор ошибки».
- Варианты перемешиваются при каждом показе. Клавиши `1`–`4` выбирают ответ, `Enter` — следующий вопрос.
- Сверху — режим, кнопка «Режимы» (назад на старт) и статистика текущего повторения: ответов, точность, серия.
- Режим хранится в адресе (`?mode=theory|calc|mix`) — после перезагрузки лента продолжится в нём же.

Итоги повторений сохраняются в `localStorage` (`concept-review:sessions`, последние 50) после каждого ответа; повторение без ответов не записывается. Сбросить статистику — удалить этот ключ в DevTools → Application → Local Storage.

Сейчас порядок внутри режима случайный. В будущем очередь будет строить алгоритм повторения (интервальное повторение по слабым темам), а страница будет брать вопросы с сервера.

## Файлы

- `static/index.html`, `static/styles.css`, `static/app.js` — страница. Оболочка кабинета (`shell.css`) берётся из `concepts/theory_page`.
- `static/questions.js` — банк вопросов. Формат описан в начале файла: `options[0]` — правильный ответ, формулы — LaTeX в `$...$`.

## Запуск

Из корня репозитория (страница берёт шрифты и логотип из `frontend/`, оболочку — из `concepts/theory_page/`):

```bash
python -m http.server 8202 --bind 127.0.0.1
```

Открыть http://localhost:8202/concepts/review_page/static/index.html

Страница статическая — её можно открыть и на сервере теории (8200) или урока (8201). В Claude Code то же самое запускает конфиг `concept-review` из `.claude/launch.json`.
