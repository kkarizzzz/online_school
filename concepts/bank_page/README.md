# Концепт: «Банк заданий»

Все прототипы ЕГЭ по номерам: выбрать номер → отметить темы → решать задания, отмечая решённые.

## Номера — `static/index.html`

- Карточки номеров 1–19, разбитые на **часть 1** (1–12, краткий ответ) и **часть 2** (13–19, развёрнутый). На карточке: номер, название, число тем и заданий. Статистики «сколько решено» в банке нет — только сколько всего заданий.
- Клик по номеру открывает **панель тем** справа (закрыть — крестик, фон или `Esc`):
  - «Все темы» — выбрать или снять все сразу; если выбрана часть, галочка в промежуточном состоянии;
  - у каждой темы — число заданий;
  - кнопка «К заданиям · N» — сколько заданий в выбранных темах; без выбранных тем неактивна.
- Выбор тем номера запоминается до закрытия вкладки (`sessionStorage`, `concept-bank:topics:<n>`). По умолчанию выбраны все.
- `index.html?n=<номер>` сразу открывает панель тем — так возвращает ссылка «Банк заданий» со страницы прототипа.

## Задания прототипа — `static/prototype.html?n=<номер>&topics=<id,id>`

- Шапка: номер и часть, название. Стрелки справа — предыдущий и следующий номер.
- **Темы** — чипы с множественным выбором; ничего не выбрано (или выбраны все) — «Все темы». **Статус** — «Не решённые» / «Решённые», повторный клик снимает. На чипах тем — сколько всего заданий в теме, у статуса счётчиков нет. Над списком — сколько всего заданий в выбранных темах, без учёта статуса: число решённых и нерешённых нигде не показывается.
- **Сортировка**: по дате добавления, по сложности, по числу решений других учеников. Кнопка рядом переключает направление: «Сначала новые / старые», «Сначала сложные / простые», «Сначала популярные / редкие». При равенстве выше новые.
- **Задание**: код `номер.тема.порядковый` (например, `6.3.04`), тема, сложность (Базовый, Средний, Сложный, Гроб — только во второй части), сколько учеников решило, дата добавления, условие (KaTeX).
  - «Показать ответ» — раскрывает верный ответ;
  - «Отметить решённым» ↔ «Решено» — отметка ставится и снимается. Карточка не исчезает из списка сразу, даже если включён фильтр «Не решённые», — чтобы список не прыгал; применится при следующем изменении фильтров.
- По 12 заданий, дальше — «Показать ещё».
- Всё состояние в адресе: `?n=6&topics=exponential,logarithmic&status=todo&sort=level&order=asc`.

Отметки хранятся в `localStorage` (`concept-bank:solved` — список id заданий) и общие для обеих страниц. Сбросить — удалить ключ в DevTools → Application → Local Storage.

## Файлы

- `static/bank.js` — заглушка банка: номера, темы и генераторы заданий по каждой теме. Задания строятся по зерну (номер, тема, позиция), поэтому одинаковые при каждой загрузке; сложность, число решивших и дата — тоже из зерна. Формат описан в начале файла.
- `static/common.js` — общее: хелперы, шкала сложности, отметки «решено».
- `static/index.html`, `static/index.js` — номера и панель тем.
- `static/prototype.html`, `static/prototype.js` — задания прототипа.
- `static/styles.css` — стили обеих страниц. Оболочка кабинета (`shell.css`) берётся из `concepts/theory_page`.

## Запуск

Из корня репозитория (страница берёт шрифты и логотип из `frontend/`, оболочку — из `concepts/theory_page/`):

```bash
python -m http.server 8204 --bind 127.0.0.1
```

Открыть http://localhost:8204/concepts/bank_page/static/index.html

В Claude Code то же самое запускает конфиг `concept-bank` из `.claude/launch.json`.
