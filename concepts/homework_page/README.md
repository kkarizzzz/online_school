# Концепт: «Домашнее задание»

Список домашних заданий, как во frontend (`pages/profile/learning/HomeworkPage`, `entities/homework/HomeworkCard`), и страница выполнения ДЗ — по образцу решения варианта из [`variants_page`](../variants_page/README.md).

## Список — `static/index.html`

**Вкладки** «Текущие», «Выполненные», «Просроченные» — как `shared/ui/Tabs`; на «Просроченных» красный бейдж с числом. Выбранная вкладка хранится в адресе (`?tab=done`).

**Карточка**: название, раздел · число задач, срок («до 13 октября, 23:59», «дедлайн истёк 5 октября», «сдано 7 октября») и прогресс («Не начато», «3 из 10 решено», «8 из 9 верно»). Кнопка:

- текущее — «Приступить к выполнению», а если ответы уже есть — «Продолжить выполнение»;
- просроченное — «Досдать» (красная рамка, как во frontend);
- выполненное — плашка «Выполнено» и «Разбор».

Все кнопки ведут на `solve.html?id=<id>`, «Разбор» — на `solve.html?id=<id>&view=result`.

## Выполнение — `static/solve.html?id=<id>`

Та же страница, что решение варианта-отработки: панель с номерами задач, «Отвечено N из M», задача с KaTeX и полем ответа, `Enter` — следующая, стрелки ← → переключают задачи. Отличия:

- нет обратного отсчёта — вместо него плашка **срока** (у просроченного ДЗ красная, «срок истёк») и секундомер «в работе»;
- ответы сохраняются сразу, закрыть страницу можно без подтверждения — при следующем открытии ДЗ продолжится с той же задачи;
- «Сдать» (сверху или «К сдаче» на последней задаче) → подтверждение, сколько задач без ответа; у просроченного — предупреждение, что сдано после срока;
- **результаты**: кольцо «решено верно», дата сдачи, время, срок, сетка задач и список ответов «ваш / верный» — по клику раскрываются условие и разбор решения. Сданное ДЗ переписать нельзя — повторное открытие показывает результаты, а карточка уходит во «Выполненные».

Начатое ДЗ хранится в `localStorage` (`concept-homework:session:<id>`), сданное — в `concept-homework:attempts`. Заглушка `answered` в `homework.js` подставляет верные ответы в первые задачи, пока своей сессии нет. Сбросить свои попытки — удалить эти ключи в DevTools → Application → Local Storage.

## Файлы

- `static/homework.js` — заглушка списка ДЗ. Формат описан в начале файла.
- `static/common.js` — задачи ДЗ, начатые и сданные попытки, статус и подписи карточки.
- `static/index.html`, `static/index.js`, `static/styles.css` — список. Оболочка кабинета (`shell.css`) — из `concepts/theory_page`.
- `static/solve.html`, `static/solve.js`, `static/solve.css` — выполнение и результаты. Генератор задач (`tasks.js`), проверка ответа, кольцо прогресса и стили страницы решения (`exam.*`, `solve.css`) берутся из `concepts/variants_page`.

## Запуск

Из корня репозитория:

```bash
python -m http.server 8205 --bind 127.0.0.1
```

Открыть http://localhost:8205/concepts/homework_page/static/index.html

В Claude Code то же самое запускает конфиг `concept-homework` из `.claude/launch.json`.
