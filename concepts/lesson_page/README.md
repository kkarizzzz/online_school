# Концепт: прохождение урока

Страница, на которую ведёт карточка урока со страницы «Теория» (`concepts/theory_page`, кнопка «Перейти к уроку» и карточка следующего урока).

Урок — цепочка шагов:

1. **Ролик** (до минуты) и под ним «Проверь себя» — 1–3 вопроса с вариантами ответа. Ошибся — можно пересмотреть ролик и ответить снова.
2. После нескольких роликов — **практика**: задачи с вариантами ответа и с вводом числа (целое, `2,5`, `5/2`). Есть подсказка и «Показать решение».
3. **Итог**: процент усвоения, что стоит повторить, переход к следующему уроку.

Следующий шаг открывается, когда на все вопросы/задачи текущего дан ответ. Прогресс хранится в `localStorage` (`concept-lesson:<id>`).

## Файлы

- `static/index.html`, `static/styles.css`, `static/app.js` — страница. Оболочка кабинета (`shell.css`) и метаданные уроков (`data.js`) берутся из `concepts/theory_page`.
- `static/lesson.js` — содержимое уроков: ролики, вопросы, задачи. Пока заполнен демо-урок `1.10.2` «Свойства логарифмов»; для уроков без содержимого показывается он же с плашкой.
- `static/media/` — ролики и постеры. **В git не попадают**, их создаёт `cut.py`.
- `cut.py` — режет `video/logarithms/logarithms.mp4` на 5 роликов по сценам → `static/media/`.

## Запуск

Все команды — **из корня репозитория**.

### 1. Нарезать ролики (один раз)

Нужен исходник `video/logarithms/logarithms.mp4` и пакет `imageio-ffmpeg` (тянет с собой ffmpeg):

```bash
py -3.12 -m pip install imageio-ffmpeg
```

```bash
py -3.12 concepts/lesson_page/cut.py
```

Если `static/media/` уже заполнена — шаг можно пропустить. Без роликов страница откроется, но видео не будет.

### 2. Поднять сервер

Сервер нужен из корня репозитория: страница берёт шрифты и логотип из `frontend/`, а оболочку и данные — из `concepts/theory_page/`.

```bash
python -m http.server 8201 --bind 127.0.0.1
```

Открыть http://localhost:8201/concepts/lesson_page/static/index.html?id=1.10.2

Параметр `id` — номер урока из плана (`x.y.z`). Остановить — `Ctrl+C`. В Claude Code то же самое запускает конфиг `concept-lesson` из `.claude/launch.json`.

Если на порту 8200 уже запущена теория, урок можно открыть и там: http://localhost:8200/concepts/lesson_page/static/index.html?id=1.10.2 — переходы между страницами работают на любом из портов.

Сбросить прогресс урока — удалить ключ `concept-lesson:<id>` в DevTools → Application → Local Storage.
