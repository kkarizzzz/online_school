# Концепт: обновлённая главная

Новый вариант публичной части сайта (`pages/main`, `widgets/*-section`). Что поменялось относительно frontend:

- **Убраны преподаватели и психологи**: нет секций `Mentors` и `MentalSupport`, в меню шапки и подвала нет пунктов «Преподаватели» и «Психологи». Из тарифов и отзывов убраны психолог, личный ментор и кланы.
- **Четыре предмета**: математика, русский, информатика, физика — блок «Предметы» с форматом экзамена, переключатель предмета на «Выпускникам», данные по нескольким предметам на «Родителям».
- **Уроки — серии коротких роликов по 60–90 секунд** с вопросом после каждого (макет урока, блок «Один урок», карточка «Теория»).
- **Главный призыв — бесплатная неделя**: кнопка «7 дней бесплатно» в шапке и на первых экранах, блок «Пробная неделя» по дням с гарантиями (без карты, без автосписаний).
- **Акцент на вкладке «Обучение»**: первый экран вместо фото показывает кусок кабинета (следующий урок, прогресс, ДЗ, пробник), а §01 — шесть вкладок кабинета (Теория, Домашнее задание, Банк заданий, Нарешка, Каталог вариантов, Быстрое повторение) со ссылками на соседние концепты.
- **«Выпускникам» и «Родителям»** — не заглушки «в разработке», а отдельные страницы.

## Главная — `static/index.html`

Шапка → первый экран → бегущая строка → §01 «Предметы» → §02 «Обучение» (карточки вкладок) → §03 «Один урок» (минутные ролики → вопрос после каждого → практика → повторение) → §04 «Пробная неделя» (7 дней по шагам, гарантии) → §05 «Для кого» → §06 «Тарифы» → §07 «Было → стало» → призыв → подвал.

**Тарифы** — подписка за число предметов («Предмет», «Пара», «Всё включено»), переключатель «Помесячно / До экзамена» (−25%, цены в `data-month` / `data-year`), экспертная проверка — отдельно, поштучно или пакетом. Цены — пример.

Меню: «Обучение» (`#learning`), «Выпускникам», «Родителям», «Тарифы» (`#pricing`). Справа — «Войти» (иконка, ведёт в концепт теории) и «7 дней бесплатно» (`index.html#trial-week`).

## Выпускникам — `static/graduates.html`

- **Таймер до экзамена**: дни, часы, минуты, секунды, тикает каждую секунду; под ним — сколько это недель и занятий. Карточка светлая в светлой теме и тёмная в тёмной. Дата ориентировочная: `EXAM_DATE` в `main.js` и `EXAM` в `graduates.js`.
- **Переключатель предмета** — закреплённая панель под шапкой, выбор в адресе (`?subject=russian`). От него зависят:
  - **план из пяти этапов** (сентябрь → июнь) с вкладками кабинета; текущий этап — с чипом «Сейчас», прошедшие приглушены;
  - **карта всех номеров** экзамена с первичными баллами по группам (части, тест и сочинение); у математики клик открывает номер в банке заданий;
  - **калькулятор**: ползунок первичных баллов → тестовый балл и полоска номеров — какие нужно решить, если набирать баллы в самом «дешёвом» порядке (`order`; шаг `[номер, баллы]` берёт часть баллов, как сочинение по русскому).
- Структура экзаменов и шкалы перевода — ЕГЭ 2026 (спецификации ФИПИ, шкалы Рособрнадзора). Названия заданий упрощены — сверить перед запуском.
- Результаты прошлого выпуска и отзывы по разным предметам.

## Родителям — `static/parents.html`

- Макет кабинета родителя на первом экране.
- §01 — четыре карточки по вопросам родителя: занимается ли (минуты по дням), делает ли домашку (сдано / в работе / просрочено), растёт ли балл (график пробников), где проседает (доля верных по номерам). Это те же данные, что в статистике ученика.
- §02 — пример еженедельного отчёта.
- §03 — как устроено обучение, коротко; §04 — частые вопросы (`<details>`).

## Файлы

- `static/styles.css` — токены и шрифты (как `globals.css`), стили всех трёх страниц.
- `static/main.js` — общее: шапка, блок пробной недели, подвал, тема (ключ `concept-theme`, общий с остальными концептами), бегущие строки, появление блоков, отсчёт дней.
- `static/home.js` — переключатель периода оплаты в тарифах.
- `static/graduates.js`, `static/parents.js` — данные-заглушки и отрисовка блоков своей страницы. Подключаются **перед** `main.js`, который потом расставляет иконки lucide.

## Запуск

Из корня репозитория:

```bash
python -m http.server 8206 --bind 127.0.0.1
```

Открыть http://localhost:8206/concepts/main_page/static/index.html

В Claude Code то же самое запускает конфиг `concept-main` из `.claude/launch.json`. Карточка «Нарешка» ведёт на `http://localhost:8100` — нужен запущенный `concept-tasks`.
