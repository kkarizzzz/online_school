§ 03 · Один урок

90 секунд на мысль.
Тема — за вечер.

Открыть пример урока

  1. Короткие ролики

    Тема разбита на несколько видео по 60–90 секунд, в каждом — одна мысль. Не нужно держать внимание 40 минут.

  2. Вопрос после каждого

    Посмотрел ролик — ответил на вопрос. Ошибся — ролик можно пересмотреть сразу, не ища нужную минуту.

  3. Практика

    Задачи из банка по теме урока с мгновенной проверкой ответа.

  4. Повторение

    Тема возвращается в быстрое повторение и домашку через несколько дней.
