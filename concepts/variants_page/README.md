# Концепт: «Каталог вариантов»

Каталог вариантов — стандартных (как на ЕГЭ) и для отработки — с фильтрами, панелью варианта и страницей решения.

## Каталог — `static/index.html`

**Фильтры** спрятаны в панель, которая открывается кнопкой «Фильтры» над списком. На кнопке бейдж — сколько групп сейчас выбрано, рядом «Найдено N из M» и «Сбросить». Открытая или закрытая панель запоминается в `localStorage` (`concept-variants:filters-open`). В панели четыре группы чипов:

- **Формат**: Стандартный — полный вариант, комплектация как на ЕГЭ (задания 1–19); Отработка — один тип заданий (например, только №13) или набор из нескольких прототипов (№1, 2, 4, 5).
- **Издатель**: Авторский, СтатГрад.
- **Сложность**: Базовый, Средний, Сложный, Гроб.
- **Статус**: Не решён, Решён.

В формате, издателе и статусе выбирается одно значение: клик по другому чипу переключает выбор (из «Отработки» сразу в «Стандартный»), повторный клик по выбранному — снова «Все». В сложности можно выбрать несколько значений сразу (например, «Сложный» + «Гроб»). Ничего не выбрано — чип «Все». На каждом чипе — сколько вариантов будет с учётом остальных групп; если вариантов ноль, чип неактивен. Фильтры хранятся в адресе (`?kind=drill&publisher=statgrad&level=hard,coffin&status=todo`) — ссылкой можно поделиться, после перезагрузки выбор сохранится.

**Сортировка** — рядом с «Фильтрами»: по дате добавления, по сложности или по популярности (сколько учеников решило вариант). Кнопка справа переключает направление и подписывает его: «Сначала новые / старые», «Сначала сложные / простые», «Сначала популярные / редкие». При равенстве выше более новые. По умолчанию — сначала новые; другой выбор попадает в адрес (`&sort=popular&order=asc`).

**Список** В строке: иконка издателя, название, издатель · формат («Как на ЕГЭ» или номера заданий отработки, например «Задания №1–3, 5») · число заданий · дата · сколько учеников решило, шкала сложности из четырёх делений, результат и кнопка — «Начать» или «Разбор». Результат стандартного варианта — во **вторичных баллах ЕГЭ** (первичные переводятся по шкале), отработки — «верно из N». «Гробы» выделены рамкой.

**Панель справа** открывается кликом по строке или кнопке (закрыть — крестик, фон или `Esc`):

- не решён — сколько заданий, время (3 ч 55 мин или без ограничения), максимум баллов, сколько учеников решило, правила и кнопка «Приступить»;
- решён — статистика последней попытки: круговая диаграмма (стандартный — вторичные баллы из 100, в центре балл; отработка — верные и неверные задания, в центре «8/10»), первичный балл или процент правильных, дата и затраченное время, сколько учеников решило, полосы по частям 1 и 2, сетка заданий (верно / частично / неверно) и кнопка «Попробовать снова».

`index.html?open=<id>` сразу открывает панель варианта — так возвращает страница результатов.

## Решение — `static/solve.html?id=<id>`

- **Стандартный** — на время: таймер обратного отсчёта 3 ч 55 мин, за 15 минут до конца желтеет, за 5 — краснеет; когда время выходит, вариант завершается сам. **Отработка** — без ограничения, секундомер просто показывает, сколько прошло.
- Сверху — панель с номерами заданий: текущее выделено, задания с ответом подсвечены, у стандартного варианта разделитель между частями. Рядом — «Отвечено N из M».
- Задание: номер, № ЕГЭ, баллы и часть, условие (KaTeX), поле ответа. Ответ сохраняется при вводе; `Enter` — следующее задание, стрелки ← → переключают задания, когда фокус не в поле.
- «Завершить» (сверху или «К завершению» на последнем задании) → подтверждение, сколько заданий без ответа → результаты.
- **Результаты**: тот же блок статистики, что в панели каталога, и список ответов «ваш / верный / баллы» — по клику раскрывается условие задания и под ним разбор решения с ответом. Кнопки «Попробовать снова» и «В каталог».

Начатая попытка хранится в `localStorage` (`concept-variants:session:<id>`) — после перезагрузки страница продолжит её с тем же таймером. Закрыть вкладку во время решения — браузер спросит подтверждение. Каталог всегда начинает новую попытку (`&start=1`). Итог пишется в `concept-variants:attempts` и заменяет заглушку из `variants.js`. Сбросить свои попытки — удалить эти ключи в DevTools → Application → Local Storage.

В концепте задания проверяются по итоговому ответу: в стандартном варианте верный ответ даёт все баллы задания, во второй части тоже. Позже вторую часть будет проверять преподаватель по критериям.

## Файлы

- `static/index.html`, `static/styles.css`, `static/app.js` — каталог. Оболочка кабинета (`shell.css`) берётся из `concepts/theory_page`.
- `static/solve.html`, `static/solve.css`, `static/solve.js` — решение варианта и результаты.
- `static/exam.js`, `static/exam.css` — общее: правила ЕГЭ (баллы за задания, шкала перевода, время), состав варианта, попытки, блок статистики, кнопки.
- `static/tasks.js` — генератор заданий 1–19: по номеру и зерну — условие, ответ и разбор (`solution`, считается из тех же чисел). Зерно — id варианта и позиция, поэтому вариант одинаковый от попытки к попытке.
- `static/variants.js` — заглушка каталога. Формат описан в начале файла.

## Запуск

Из корня репозитория (страница берёт шрифты и логотип из `frontend/`, оболочку — из `concepts/theory_page/`):

```bash
python -m http.server 8203 --bind 127.0.0.1
```

Открыть http://localhost:8203/concepts/variants_page/static/index.html

В Claude Code то же самое запускает конфиг `concept-variants` из `.claude/launch.json`.
