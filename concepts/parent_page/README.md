# Концепт: «Кабинет родителя»

Три варианта главной кабинета родителя на одной странице — чтобы сравнить и выбрать. Отвечают на обещания со страницы «Родителям» (`main_page/static/parents.html`): «четыре вопроса — четыре ответа», еженедельный отчёт «было → стало», «если что-то пошло не так — кабинет скажет первым». Кабинет только для просмотра.

Оболочка — как в кабинете ученика (`theory_page/static/shell.css`). В шапке — переключатель детей (у каждого точка-светофор), в сайдбаре — варианты. На телефоне сайдбар скрыт, варианты — полоской под шапкой.

## Варианты

**A · Четыре ответа** — `#/a`. Дашборд для тех, кто хочет видеть всё. Наверху четыре карточки-ответа с вердиктом (иконка + слово + цвет): «Занимается ли?» (дней из 7, минуты), «Делает ли домашку?» (сдано / просрочено), «Растёт ли балл?» (изменение за месяц), «Где проседает?» (самый слабый номер). Клик — к подробностям: тепловая карта занятий за 8 недель, список ДЗ (просроченные сверху), график пробников по предмету с линией цели, сетка номеров 1–19 с долей верных.
*Плюсы:* всё на одном экране, близко к лендингу. *Минусы:* много цифр, родителю надо самому делать вывод.

**B · Отчёт недели** — `#/b`. Главная — это то же письмо, что приходит в воскресенье, только с навигацией по неделям. Заголовок-вывод («Хорошая неделя: занимался 5 дней из 7»), полоска дней, таблица «неделей раньше → эта неделя» с изменениями, «Обратите внимание» (что уже сделала платформа), «О чём поговорить за ужином» и лента событий по дням.
*Плюсы:* читается как текст, задаёт тон разговора, не провоцирует допрос. *Минусы:* хуже для быстрого «а что сегодня».

**C · Светофор** — `#/c`. Один экран под телефон: общий статус (зелёный / жёлтый / красный) с одной фразой, полоска недели, светофор по каждому предмету (по плану / отстаёт на N уроков, последний пробник) и список сигналов с одним действием на каждый («Напомнить ребёнку», «Написать куратору» — заглушки).
*Плюсы:* ответ за 10 секунд, минимум тревоги, когда всё хорошо. *Минусы:* прячет детали — нужен переход в A.

**Отчёты и сигналы** — `#/settings`. Общее для всех вариантов: каналы отчёта (почта / Telegram) и день отправки; пороги сигналов — сколько дней без занятий, просрочка ДЗ, падение пробника. Пороги сразу меняют «Светофор» и вердикты. Блок «Прозрачность»: ребёнок видит, что кабинет подключён.

Как считаются сигналы (`stats()` в `app.js`): нет занятий ≥ порога дней — красный; просроченные ДЗ — жёлтый (две и больше — красный); пробник упал больше порога; отставание от плана ≥ 3 уроков. Общий статус — худший из сигналов.

## Данные

- `static/data.js` — заглушка по зерну: двое детей (Алексей, 11 класс, три предмета, в целом всё хорошо; Маша, 10 класс, два предмета, «буксует»), 56 дней активности, ДЗ, пробники, точность по номерам, лента событий за две недели. Формат — в начале файла.
- Выбор ребёнка, вариант, вкладка предмета и настройки — `localStorage` под `concept-parent:*`.

## Запуск

Из корня репозитория:

```bash
python -m http.server 8212 --bind 127.0.0.1
```

Открыть http://localhost:8212/concepts/parent_page/static/index.html

В Claude Code то же самое запускает конфиг `concept-parent` из `.claude/launch.json`.
