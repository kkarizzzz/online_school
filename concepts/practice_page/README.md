# Концепт: «Нарешка» по номерам

Новый вариант выбора тем для «Нарешки» (`concepts/tasks_page`, `widgets/practice-feed`). Там темы — плоская сетка карточек, где подтемы идут одной строкой через точку. Здесь — только **номера ЕГЭ и их подтемы**, каждая подтема отдельной строкой, и два режима: **«Торнадо»** и **«Персональный»**.

## Главная — `static/index.html`

- **Торнадо** — задачи из всех номеров первой части (1–12) вперемешку, с прогрессом.
- **Персональный** — пока подборка пустая, одна кнопка «Собрать подборку». Если что-то выбрано — сводка («№1 целиком · №6: 1 подтема · сложность: средний, сложный»), прогресс, «Решать» и «Изменить». «Собрать подборку» и «Изменить» открывают страницу с номерами ЕГЭ — на главной номеров нет.
- **Последние подборки** — три последние запущенные персональные подборки вместе со сложностью (новые сверху, повторный запуск поднимает наверх): состав, сложность, число заданий, когда запускали, прогресс. «Решать» делает подборку персональной и открывает ленту, «Изменить» — делает персональной и открывает настройку. Хранятся в `localStorage` (`concept-practice:recent`); блок скрыт, пока истории нет.

## Настройка персонального — `static/personal.html`

- Те же номера 1–19 с подтемами, у каждой подтемы и у номера — галочка. Галочка у номера отмечает или снимает все его подтемы; если отмечена часть — состояние «частично», в карточке «Выбрано 1 из 4».
- Внизу панель «Выбрано N подтем из M номеров · K заданий», «Очистить» и «Решать» (`index.html?scope=personal`).
- **Сложность** — чипы «Базовый», «Средний», «Сложный», «Гроб» (гроб бывает только во второй части), можно выбрать несколько, хотя бы один остаётся. Сколько заданий каждого уровня, на чипах не показывается. Задания других уровней в ленту не попадают; числа заданий на странице считаются уже с учётом сложности. Если в выбранных темах нет заданий такой сложности, «Решать» неактивна.
- Подборка и сложность сохраняются сразу, в `localStorage` (`concept-practice:personal`, `concept-practice:levels`).

## Лента

- Шапка: режим или номер / подтема, решено и серия за сессию. Сколько всего заданий в подборке и сколько из них решено, во время решения **не показывается** — ни полоской, ни на чипах: лента бесконечная.
- В «Торнадо» выбора тем нет — только задание. В остальных: внутри одного номера — чипы подтем, их можно включать и выключать прямо в ленте; если номеров несколько — чипы номеров, клик оставляет только этот номер.
- Задание: код `номер.подтема.порядковый`, путь «№6 Простейшие уравнения › Логарифмические уравнения», сложность, условие (KaTeX), поле ответа, «Показать решение» (пошаговое решение и ответ; повторное нажатие скрывает), «Похожее» (та же подтема; появляется после ответа — верного или нет — или после просмотра решения), «Следующее» (сначала нерешённые и ещё не показанные). Кнопка «В персональный» добавляет подтему текущего задания в персональную подборку.
- Подборка и задание — в адресе: `?scope=6&task=6-quadratic-3`. Токены: `part1` (Торнадо), `personal`, номер (`6`), подтема (`6.quadratic`).

## Данные

Номера, подтемы, задания и их решения (`solution`) — из заглушки банка `bank_page/static/bank.js`, хелперы и отметки «решено» — из `bank_page/static/common.js`. Поэтому отметки **общие с банком заданий** (`concept-bank:solved`): верный ответ в ленте отмечает задание решённым.

## Файлы

- `static/practice.js` — ключи подтем, персональная подборка, подборка ↔ адрес, название подборки. Общий для обеих страниц.
- `static/index.html`, `static/app.js` — главная и лента.
- `static/personal.html`, `static/personal.js` — настройка персонального режима.
- `static/styles.css` — стили; оболочка кабинета (`shell.css`) — из `concepts/theory_page`.

## Запуск

Из корня репозитория:

```bash
python -m http.server 8207 --bind 127.0.0.1
```

Открыть http://localhost:8207/concepts/practice_page/static/index.html

В Claude Code то же самое запускает конфиг `concept-practice` из `.claude/launch.json`.
