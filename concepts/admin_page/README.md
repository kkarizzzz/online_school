# Концепт: «Кабинет преподавателя»

Админка для работы с банком заданий, выдачи и проверки домашних заданий и ведения учеников. Одна страница `static/index.html`, разделы переключаются по адресу (`#/...`). Оболочка — как в кабинете ученика (`theory_page/static/shell.css`), сайдбар с разделами преподавателя; на телефоне и планшете — полоска разделов под шапкой.

## Разделы

**Обзор** — `#/overview`. Что требует внимания сегодня: KPI (ученики, активные ДЗ, задачи второй части на проверке, средняя точность), список «Ждут проверки» с кнопкой «Проверить все», ближайшие сроки с долей сдавших и «Нужна помощь» — ученики с просрочками, низкой точностью или давно не заходившие, с их слабыми номерами.

**Банк заданий** — `#/bank`. Все задания из `bank_page` (номера 1–19 × темы-прототипы): номер — кнопками, тема, сложность, сортировка (новые / по номеру / сложные / реже всего решали), поиск по тексту, теме и id. Галочка отбирает задачу в **корзину** — плашка снизу «N задач отобрано → Собрать ДЗ». Карандаш открывает редактор: условие с формулами в `$…$` и живым предпросмотром, ответ, сложность; правки банковских задач можно откатить («Вернуть исходное»). «Новое задание» добавляет своё в выбранную тему.

**Домашние задания** — `#/homework`. Вкладки «Активные» / «Завершённые»: кому выдано, срок, полоска «сдали N из M», средний результат, бейдж «на проверку».

**Карточка ДЗ** — `#/homework/<id>`. KPI сдачи и **матрица ученик × задача**: зелёный — верно, жёлтый — частично, красный — неверно, «?» — ждёт проверки, пусто — нет ответа. Снизу — процент верных по каждой задаче и подсказка, какие задачи стоит разобрать на занятии (решили меньше половины). Действия: продлить срок на 2 дня, напомнить не сдавшим (заглушка), проверить.

**Проверка второй части** (модальное окно из обзора, карточки ДЗ или клика по ячейке №13–19): условие, фото решения (заглушка), баллы по критериям ЕГЭ с максимумом номера (13, 15, 16 — 2; 14, 17 — 3; 18, 19 — 4), комментарий ученику. Очередь — «Сохранить и далее» переходит к следующей непроверенной задаче.

**Конструктор ДЗ** — `#/homework/new`. Четыре шага: название и раздел; задачи — из корзины банка и/или **автоподбор** «номер × сложность × количество», с перестановкой и удалением; кому — группы целиком и отдельные ученики; срок (быстрые кнопки «через 2 дня / неделю / 2 недели») и настройки (показ ответов после срока, досдача). Справа — итог: задач (часть 1 + часть 2), первичных баллов, примерное время, сколько учеников получат.

**Ученики** — `#/students`. Таблица с фильтром по группе и сортировкой (слабые, просрочки, давно не заходили): точность, полоска 19 номеров по цвету, сдано / просрочено / в работе, последний заход.

**Ученик** — `#/students/<id>`. KPI, **карта номеров** (клик — задания номера в банке), история ДЗ, заметка преподавателя. «ДЗ по слабым номерам» открывает конструктор с тремя самыми слабыми номерами ученика по 3 задачи (`#/homework/new?student=<id>&weak=1`).

Поиск в шапке по Enter открывает ученика или ДЗ по совпадению в имени / названии.

## Данные

- `static/data.js` — заглушка: группы, 15 учеников с точностью по номерам, 5 выданных ДЗ и сдачи по ним. Генерируется по зерну — одинаково при каждой загрузке. Формат описан в начале файла.
- Задания — `concepts/bank_page/static/bank.js` (`window.BANK`).
- Всё, что меняет преподаватель, хранится в `localStorage` под `concept-admin:*`: `homework` (выданные ДЗ), `deadlines` (продления), `reviews` (баллы и комментарии), `task-edits` и `custom-tasks` (правки и свои задания), `basket`, `notes`. Сбросить — удалить эти ключи в DevTools → Application → Local Storage.

## Файлы

- `static/index.html` — оболочка, сайдбар, корзина, модальное окно.
- `static/app.js` — роутер и все разделы.
- `static/styles.css` — стили разделов; кнопки и токены статусов — из `variants_page/static/exam.css`.

## Запуск

Из корня репозитория:

```bash
python -m http.server 8210 --bind 127.0.0.1
```

Открыть http://localhost:8210/concepts/admin_page/static/index.html

В Claude Code то же самое запускает конфиг `concept-admin` из `.claude/launch.json`.
